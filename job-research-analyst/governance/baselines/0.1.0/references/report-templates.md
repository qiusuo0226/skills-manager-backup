# 交付物模板结构

> 本文件定义三类交付物的标准结构：①公司深度介绍Word文档 ②岗位薪资与福利待遇对比表 ③员工评价与风险提示表。实际生成时根据用户输入的公司数量和岗位方向灵活调整，但核心模块不得省略。

---

## 一、公司深度介绍 Word 文档

**文件名格式：** `{公司名}_深度介绍_{YYYYMMDD}.docx`

### 文档结构

#### 封面/标题区
- 标题：`{公司名} 求职深度调研报告`
- 副标题：面向 `{用户岗位方向}` 岗位 / `{目标城市}`
- 报告日期、数据采集时间范围
- 免责声明：本报告基于公开信息整理，仅供求职参考，不构成入职建议；信息可能存在滞后，请以官方最新信息为准。

#### 1. 公司基本信息
| 项目 | 内容 | 来源 |
|------|------|------|
| 公司全称 | | 工商登记 |
| 成立时间 | | 工商登记 |
| 注册资本/实缴资本 | | 工商登记 |
| 法定代表人 | | 工商登记 |
| 公司类型 | 国企/民企/外企/上市公司 | 工商登记 |
| 员工规模（参保人数） | | 工商登记（注明年份） |
| 上市情况 | 如上市，注明板块/股票代码 | 交易所 |
| 总部/分支机构 | | 工商登记/官网 |
| 主营业务 | | 官网/财报 |

#### 2. 业务与行业地位
- 主营业务板块介绍（分板块说明）
- 核心客户/标杆项目（ToG公司重点列政府客户、中标项目）
- 行业地位：市场份额/排名/行业标签（如"政务信息化TOP10"），必须注明来源
- 竞争对手：同赛道主要玩家
- 近期业务动态：近1年新签合同、新产品、新业务线

#### 3. 扩张与收缩信号
- **扩张信号：** 融资情况、招聘规模增长、新城市/新业务线布局、中标大单、分支机构新增
- **收缩信号：** 裁员传闻/公告、岗位冻结、业务线关停、办公场地缩减、高管频繁变动、应收账款异常
- **综合判断：** 分业务线说明，不得笼统下结论；标注每个信号的来源和证据等级

#### 4. 财务健康度（如为上市公司或有公开数据）
- 营收/净利润趋势（近2-3年）
- 应收账款占比（ToG公司重点关注）
- 现金流状况
- 研发投入占比
- 数据来源：财报/年报，标注报告期

#### 5. 组织与职级体系
- 组织架构（如可获取）
- 职级体系（P级/M级等，如可获取）
- 晋升机制（据员工评价整理）
- 培训与成长资源

#### 6. 适合该用户背景的匹配度分析
- 用户背景摘要（岗位方向、经验年限、行业偏好、当前薪资）
- 匹配点：公司业务/岗位要求与用户经验的契合之处
- 差距点：用户可能欠缺的能力或资质
- 投递建议：建议投递的具体岗位/业务线、投递渠道、简历重点

## 三、员工评价与风险提示表

**文件名格式：** `{公司名}_员工评价与风险提示_{YYYYMMDD}.xlsx`（或在Word中呈现）

### 表格结构

#### Sheet 1：员工评价汇总
| 维度 | 评分/评价 | 评价条数 | 正面评价摘要 | 负面评价摘要 | 数据来源 | 时间范围 |
|------|----------|---------|-------------|-------------|---------|---------|
| 薪资福利 | | | | | | |
| 工作强度/加班 | | | | | | |
| 团队氛围 | | | | | | |
| 管理层/领导 | | | | | | |
| 职业成长/晋升 | | | | | | |
| 工作稳定性 | | | | | | |
| 办公环境 | | | | | | |

**说明：**
- 评分为看准网等平台的聚合评分（5分制），如无聚合评分则写"据X条评价整理"。
- 正面/负面摘要必须提炼共性，不得引用单条极端评价。
- 区分在职/离职员工评价倾向。

#### Sheet 2：风险提示清单
| 风险等级 | 风险类型 | 具体描述 | 证据来源 | 证据等级 | 对用户的影响 | 建议 |
|---------|---------|---------|---------|---------|-------------|------|
| 高/中/低/待核实 | 裁员/薪资拖欠/管理混乱/业务收缩/回款困难/加班严重/等 | | | A/B/C/D | | |

**风险等级判定标准：**
- **高：** 有A级/B级证据确认，且对入职后收入/稳定性有重大影响（如已确认裁员、薪资拖欠、业务线关停）。
- **中：** 有B级/C级证据，多名员工反映，可能影响工作体验（如加班严重、晋升困难、绩效打折）。
- **低：** 有C级证据，个别员工反映，影响有限。
- **待核实：** 仅有D级线索，无法确认，建议面试时直接询问。

#### Sheet 3：面试建议提问清单
| 关注方向 | 建议提问 | 目的 |
|---------|---------|------|
| 薪资结构 | "这个岗位的薪资构成是怎样的？基本工资和绩效比例？绩效过往发放情况？" | 核实绩效是否足额发放 |
| 公积金 | "公积金缴纳基数和比例是多少？是按实际工资还是固定基数？" | 核实隐性收入 |
| 加班 | "团队目前加班情况如何？有调休或加班费吗？" | 核实工作强度 |
| 团队稳定性 | "这个岗位是新增还是替补？团队近半年人员流动情况？" | 判断是否坑位 |
| 业务前景 | "这个业务线/项目的预算和人员规划是怎样的？" | 判断业务是否稳定 |
| 出差 | "岗位出差频率和补贴标准是怎样的？" | 核实出差情况 |
| 年终奖 | "年终奖通常是几个月？近三年实际发放情况？" | 核实年终是否靠谱 |

## 四、交付物生成注意事项

1. **Word文档**使用 `python-docx` 生成，确保中文字体正常（设置宋体/微软雅黑），标题层级清晰，表格边框完整。
2. **Excel表格**使用 `openpyxl` 生成，表头加粗，列宽自适应，重要数据标注颜色（如风险高的标红）。
3. 所有交付物末尾必须附**信息来源清单**，列出所有引用来源的名称、URL、访问时间。
4. 如用户只要求部分交付物，按用户要求执行，不必全部生成。
5. 如目标公司为未上市公司且公开信息极少，必须在报告开头注明"该公司公开信息有限，部分内容基于有限样本，仅供参考"。
6. 报告中不得出现任何无法溯源的数据，宁可留空标注"待补充"，也不编造。
