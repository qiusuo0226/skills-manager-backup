# 信息来源清单与使用方法

> 本文件列出求职调研可用的公开信息来源、各自能拿到什么数据、以及使用时的注意事项。所有数据必须标注来源，不得跨来源混写后不标注。

## 一、岗位薪资来源

| 来源 | 能拿到什么 | 局限与注意 |
|------|-----------|------------|
| BOSS直聘 / 智联招聘 / 前程无忧 / 猎聘 | 在招岗位的薪资区间、岗位要求、公司规模标签、所在城市 | 薪资是企业挂牌区间，非实际offer；高端岗位常写"面议"；同一公司不同HR挂牌差异大；需统计多个样本取区间，不得用单条挂牌当结论 |
| 脉脉 | 员工爆料薪资、职级体系、加班情况 | 匿名爆料，单条不可信；需多条交叉验证；情绪化表达多，需去极值 |
| 看准网 / 职友集 | 员工自评薪资、面试经验、公司评分 | 样本量小的公司数据波动大；薪资自评可能含年终奖/补贴，口径不清需注明 |
| 拉勾网（互联网方向） | 互联网岗位薪资、公司融资阶段 | 偏互联网，ToG/传统行业覆盖弱 |
| 各公司招聘官网 / 公众号 | 官方JD、校招薪资公示 | 社招薪资常不公示；校招薪资有参考价值但与社招不同 |

**薪资调研硬性规则：**
- 至少收集 5 条以上同岗位同城市的挂牌样本，给出区间（最低-最高-中位数），不得只给一个数。
- 区分"挂牌薪资"与"实际offer"，挂牌只能说"市场挂牌区间"，不能说"实际能拿到"。
- 年终奖、绩效、补贴单独列，不得并入月薪后不说明。
- 若样本不足 5 条，必须标注"样本量不足，仅供参考"。

## 二、公司规模与工商信息来源

| 来源 | 能拿到什么 | 注意 |
|------|-----------|------|
| 企查查 / 天眼查 / 爱企查 | 注册资本、实缴资本、成立时间、法定代表人、股东结构、分支机构数量、参保人数、司法风险、经营异常、行政处罚 | 参保人数是最接近真实员工规模的指标，但可能滞后；注册资本不等于实缴；分支机构数量反映扩张但不等于盈利 |
| 国家企业信用信息公示系统 | 官方工商登记、年报、行政处罚 | 权威但信息更新有延迟；年报中的营收/利润为企业自主申报，可不公示 |
| 上市公司公告（巨潮资讯网 / 港交所披露易 / SEC EDGAR） | 财报、员工人数、营收、业务板块、重大合同、裁员/扩张公告 | 仅覆盖上市公司；子公司数据需看合并报表附注 |
| 公司官网 / 官方公众号 | 官方介绍、客户案例、新闻动态 | 宣传口径，需与第三方信息交叉验证 |

**公司规模判断规则：**
- 优先用"参保人数"作为员工规模指标，标注数据年份。
- 上市公司用财报披露的员工总数，标注报告期。
- 不得用"注册资本"当公司规模。
- 分支机构数量可作为扩张信号，但需结合成立时间和参保人数判断是否为空壳。

## 三、公司扩张/收缩信号来源

| 信号类型 | 来源 | 具体看什么 |
|---------|------|-----------|
| 融资/上市 | 企查查融资历史、36氪/IT桔子融资报道、招股书 | 最新融资轮次、金额、投资方；融资后是否扩张 |
| 招聘扩张 | BOSS/猎聘在招岗位数量变化、新增岗位城市、校招规模 | 在招岗位数环比增长、新城市开岗、大量急招=扩张；岗位冻结/批量下架=收缩 |
| 裁员/收缩 | 脉脉爆料、新闻报道、劳动仲裁公告（企查查司法风险）、上市公司裁员公告 | 裁员比例、涉及部门、是否有N+1；劳动仲裁数量激增是风险信号 |
| 业务变化 | 公司官网新闻、公众号、中标公告（中国政府采购网）、行业媒体 | 新签大单/标杆项目=扩张；丢标/业务线关停=收缩；政府预算缩紧对ToG公司影响大 |
| 高管变动 | 企查查高管变更、新闻 | 核心高管离职、频繁换帅是不稳定信号 |
| 办公场地 | 企查查注册地址变更、招聘信息办公地址 | 缩减办公面积/搬迁到更便宜区域=收缩信号 |

**信号判断规则：**
- 单一信号（如一条脉脉裁员爆料）不得直接下结论，需至少 2 个独立来源交叉验证。
- 扩张信号和收缩信号可能同时存在（如某业务线扩张、另一业务线裁员），需分业务线说明，不得笼统说"公司在扩张/收缩"。
- ToG行业特别关注：政府预算变化、中标公告、应收账款周期（财报中应收账款占比过高=回款风险）。

## 四、员工工作体验评价来源

| 来源 | 能拿到什么 | 注意 |
|------|-----------|------|
| 脉脉 | 加班强度、薪资发放、管理层风格、裁员动态 | 匿名，情绪化；正面评价可能是公关；需看多条并区分岗位/部门 |
| 看准网 | 公司评分（5分制）、各维度评分（薪资/加班/氛围/成长）、员工点评 | 样本量<20时评分不可靠；离职员工评价偏负面，在职员工评价偏正面，需综合 |
| 知乎 | 公司话题下的长文回答、面试体验 | 长文信息量大但可能是个例；注意回答时间，超过2年的评价参考价值低 |
| 小红书 | 年轻员工/校招生体验、办公环境、福利 | 偏正面/生活向，负面评价容易被删；样本偏年轻岗位 |
| 玻璃门（Glassdoor，外企） | 外企员工评分、薪资、面试 | 国内公司数据少 |

**员工评价处理规则：**
- 必须区分"在职员工"与"离职员工"评价，两者倾向不同。
- 必须标注评价时间范围，优先采用近 1 年内的评价。
- 单条评价无论正负，都只能作为"有员工反映"，不得上升为"公司普遍情况"。
- 提取共性问题时，需至少 3 条独立评价提到同一问题，才可写为"多名员工反映"。
- 加班强度需区分部门（如研发vs销售vs交付），不得笼统说"公司加班多"。

## 五、行业与宏观背景来源

| 来源 | 用途 |
|------|------|
| 工信部 / 发改委 / 财政部官网 | 行业政策、政府预算方向、信创/数字化政策 |
| 中国政府采购网 | ToG项目中标公告、预算金额、竞争对手 |
| 行业研究报告（艾瑞 / 易观 / 头豹 / 赛迪） | 行业规模、增速、竞争格局 |
| 上市公司年报/半年报 | 行业头部公司经营数据，可作为对标 |
| 新闻媒体（36氪 / 钛媒体 / 财新 / 第一财经） | 行业动态、公司重大事件 |

## 六、来源优先级与交叉验证

**可信度从高到低：**
1. 官方文件（工商登记、上市公司公告、政府中标公告、法院判决）
2. 权威媒体报道（有记者署名、可核实的新闻）
3. 招聘平台大数据（多样本统计）
4. 员工评价平台聚合数据（看准网评分等）
5. 匿名爆料（脉脉单条、知乎单条）——仅作线索，需验证

**交叉验证要求：**
- 任何写入最终报告的"事实性结论"，必须有至少 1 个高可信度来源，或 2 个以上中可信度来源相互印证。
- 仅有匿名爆料支撑的信息，必须标注"据匿名爆料，未经验证"，且不得作为核心结论。
- 数据冲突时，以更高可信度来源为准，并在报告中注明差异。
