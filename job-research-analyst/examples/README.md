# 使用示例

看怎么开口、助手问什么、你怎么回、会交出什么。问法是真的；公司名和人名是假的。贯穿始终：林夏想从政务项目经理岗位跳槽，先摸清几家目标公司。

默认产出三件套。只有明确说不要文件时才口头摘要（先确认一句）。

```mermaid
flowchart LR
    A["说要调研哪家公司、什么岗位、哪个城市"] --> B["声明三件套，缺的一次问清"]
    B --> C["公开来源采集并交叉验证"]
    C --> D["填模板 / 校验 / 公司介绍与对比表"]
```

建议先看 01。事故句式看 09。明确不要文件看 03。信息很少看 04。对比几家看 05。助手不该把单条评价写成「公司就是这样」看 08。

| 文件 | 看什么 | 你开口可以这样说 |
|---|---|---|
| [01-调研一家公司.md](01-调研一家公司.md) | 先声明三件套，再问岗位/城市/简历 | 「帮我调研 XX 公司」 |
| [02-一句话带齐调研范围.md](02-一句话带齐调研范围.md) | 开头说全了，就不再问 | 「调研这三家，岗位是……城市是……」 |
| [03-只问薪资不要完整报告.md](03-只问薪资不要完整报告.md) | 明确不要文件 → 确认句 → 口头 | 「先不要出报告，告诉我薪资范围就行」 |
| [04-公开信息很少.md](04-公开信息很少.md) | 信息不够就标明，不编 | 「这家小公司怎么样」 |
| [05-对比多家公司.md](05-对比多家公司.md) | 薪资福利对比表 | 「这几家帮我做薪资福利对比」 |
| [06-员工评价与风险.md](06-员工评价与风险.md) | 评价汇总和风险分级 | 「员工怎么说，有什么坑」 |
| [07-ToG行业调研.md](07-ToG行业调研.md) | 政务信息化要多看中标和回款 | 「这几家 ToG 公司稳不稳」 |
| [08-不把个例当普遍.md](08-不把个例当普遍.md) | 单条爆料不能当结论 | 「脉脉有人说他们裁员了」 |
| [09-查一下这个公司.md](09-查一下这个公司.md) | 事故句式默认三件套 | 「查一下这个公司」 |
