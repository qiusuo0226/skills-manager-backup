# 接手读取

命中「读一下交接文件 / 接着上次」时加载本文件。本路由**只读，不写盘**。

「接着上次」要有交接文件语境（上次写过会话交接）。找不到交接文件时只问路径，不写盘、不编造。

## 1. 定位文件

1. 用户给了路径 → 用它。
2. 没给 → 在当前工作区与 `{用户主目录}/Downloads` 下找文件名含「会话交接」的 md，列出候选让用户选。
3. 都没有 → 问路径。不编造内容，不凭印象复述。

## 2. 读

读全文。先看头注与第 0 节概览，再按需看第 10 节话题详情、第 11 节决策与弯路。

旧格式文件（没有第 0 节）：从第 1、4、6、7 节取任务、进度、未决事项与建议。

## 3. 复述

≤5 句：任务、当前焦点（`T{n}`）、下一步、未决事项。只说文件里有的。

## 4. 核对

- 文件里引用的路径逐个查是否存在：头注「当前工作稿」、第 3 节依据材料、话题「相关文件」。
- 路径不存在、「当前工作稿」缺失、头注「自动交接」状态与实际不符 → 在复述后标「可能过期」，列出是哪条。
- 不改记忆文件；不按过期路径继续做。

## 5. 等确认

问一句：「以上对吗？从 T{n} 接着做？」用户确认前不动手改任何文件（硬闸 7）。

## 6. 已否决方案不重提

第 11 节或话题「讨论要点」里已否决的方案，接手后不重新提议；除非用户主动重提，或前提已变并说明变在哪。

## 7. 确认之后

按用户确认的方向继续。要更新记忆文件时回到 `01-write-memory.md`（整份交接 / 追加原话）或 `03-auto-handoff.md`（自动交接）。
