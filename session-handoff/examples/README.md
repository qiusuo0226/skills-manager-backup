# 使用示例

看怎么开口、助手问什么、你怎么回、会写出什么。

人名和项目名是假的，问法是真的。贯穿始终：林夏在 `api-upgrade` 文件夹里写「接口改造说明」，要把内部接口改成走统一网关。对话已经很长，下一场要接着干。

```mermaid
flowchart LR
    A["项目文件夹"] --> B["说：会话交接"]
    B --> C["路径已给则写；没给先问"]
    C --> D["一份记忆 markdown"]
    D --> E["下一场先读这份"]
```

建议先看 [01](01-整份会话交接.md)。没给路径看 [03](03-路径未指定会先问.md)。只想记下原话看 [04](04-记住下面的话.md)。

| 文件 | 看什么 | 你开口可以这样说 |
