## 这版改了什么

- 记忆文件顶部多了第 0 节概览（几行可单独读 + 话题索引 + 当前焦点），底部多了第 10 节话题详情、第 11 节决策与弯路；第 1～9 节编号和标题不变，「第 9 节」照旧是用户要记住的原话。
- 多话题对话按问题拆成 T1、T2……，被打断又回来的并回同一编号；单话题不拆。
- 每条事实标来源（对话 / 文件路径）；否决的方案和失败尝试写明理由。
- 落盘前按固定清单自检：无编造、无秘密、待确认不进已拍板、有来源、仍是一份文件。
- 新口令「读一下交接文件 / 接着上次」：只读，先复述、标出失效路径，等你确认再动手。
- 新口令「开启自动交接 / 关闭自动交接」：开启后在拍板、换话题、完成一步时增量更新同一份记忆文件，只回一行提示；常驻规则片段（写进 `AGENTS.md` 等）先问再写；平台 hook 仅作可选说明。
- `SKILL.md` 硬闸 5 条 → 7 条（1、3、5 补文，新增 6、7），原 1～5 无一放宽。
- 开发仓治理：`skill-governance.md` §13 白名单补 `examples/`（不进分发包）。

## 使用者要做什么

- [x] 用新 zip / 新目录替换已安装的 Skill
- [x] 无需迁移工作区（默认）
- [x] 其他：0.1.0 格式的旧记忆文件不用手改，下次「会话交接」或合并时自动补齐第 0、10、11 节，原内容与第 9 节原话保留

## 不兼容说明

无。新增的是口令与记忆文件里的节，旧口令、旧节编号照旧可用。

## 回滚

回到上一版分发包，对照 `governance/baselines/0.1.0/`。已生成的 0.2.0 格式记忆文件仍是普通 markdown，0.1.0 可读（多出的第 0、10、11 节下次合并时当作用户内容保留）。若开启自动交接时写过常驻规则片段，需在 `AGENTS.md` / `CLAUDE.md` / Cursor 规则里按 `session-handoff:auto-handoff BEGIN` 到 `END` 标记整段手动删除。
