# 示例：口令不会写进记忆

表格或对话里出现了口令、密钥、云方人员手机，记忆 markdown **不抄这些值**。用户在「帮我记住下面的话」里原文要求记住的除外，仍只记原文。

> 假例子：林夏打开过一张资源表，里面有测试库口令 `Passw0rd!`。同时说过「不要把口令写进说明」。

---

**你**

> 会话交接，写到当前目录。

**助手**

> 写好了：`api-upgrade/api-upgrade会话交接.md`。
>
> 资源表里的口令没有写入记忆。约束里记了「口令不准写进说明」，没有记口令本身。

---

若你就是要记住某句原文（哪怕里面有口令），用 [04-记住下面的话.md](04-记住下面的话.md)，助手只存你给出的那句，不扩散到其它节。
